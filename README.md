**Status:** Commercial / Proprietary

## 📌 Overview

PIMS is a project and business information management platform designed to bring operational information into one structured system.

The project is being developed with a focus on:

- Project-based data management
- Structured business records
- Customer and payment workflows
- Money receipt management
- Web and mobile access
- API-driven architecture
- Future automation and reporting

> This repository is a **public case study only**. The production source code and private business data are not included.

---

## 🎯 Problem

Many project-based businesses manage important information across spreadsheets, documents, messages and separate tools.

This can create:

- Duplicate data
- Difficult information retrieval
- Manual reporting
- Inconsistent records
- Repetitive administrative work
- Limited visibility across project operations

PIMS is designed around the idea of keeping these workflows in a structured, centralized system.

---

## 💡 Solution

PIMS provides a centralized application layer where project-related information can be managed through structured interfaces and APIs.

The system is designed to support a workflow such as:

```
Project
   ↓
Units / Records
   ↓
Customer & Operational Data
   ↓
Payments
   ↓
Money Receipt
   ↓
Reports / Business Operations
```

## 🏗️ Technical Architecture

The project uses a modern web/mobile architecture.

```
┌─────────────────────────┐
│      Web Application    │
│      React + Vite       │
└────────────┬────────────┘
             │
             │ REST API
             ▼
┌─────────────────────────┐
│       Node.js API       │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│       Data Layer        │
│   PostgreSQL / Cloud DB │
└─────────────────────────┘
             ▲
             │
┌────────────┴────────────┐
│     Android / Mobile    │
│      Capacitor-based    │
└─────────────────────────┘
```

### Core Technologies

| Layer | Technology |
|---|---|
| Frontend | React |
| Build Tool | Vite |
| UI | MUI |
| Backend | Node.js |
| API | REST |
| Mobile | Android + Capacitor |
| Database | PostgreSQL-compatible / Cloud DB |
| Deployment | Vercel + backend hosting |
| Development | GitHub + AI-assisted development |
